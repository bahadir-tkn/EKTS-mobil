Make a Node

Nodes are automatically created when connection made between element and connection line.

 

Delete Node

To delete a node:

  1. Select node by clicking left mouse button in it. Selected node will convert to red color.
  2. Click delete button on tool bar or press delete key from the keyboard.

When node deleted connection lines connected to the node will also be deleted.
