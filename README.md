# EKTS Mobil

Elektrik Kumanda Teknikleri Simülatörü (EKTS) programının mobil sürümü. Telefona
uygulama gibi kurulabilen bir web uygulamasıdır (PWA) ve internet olmadan da çalışır.

Uygulama adresi: https://bahadir-tkn.github.io/EKTS-mobil/

## Telefona kurma

- **Android (Chrome):** adresi açın, menüden **Ana ekrana ekle / Uygulamayı yükle**.
- **iPhone (Safari):** adresi açın, **Paylaş → Ana Ekrana Ekle**.

İlk açılıştan sonra program, örnek devreler ve yardım sayfaları telefona kaydedilir;
sonraki açılışlarda internet gerekmez.

## Masaüstü programdan farklar

Program masaüstündeki EKTS 1.0.3 ile aynı çalışır. Fare yerine parmakla kullanıldığı için:

| Bilgisayarda | Telefonda / tablette |
| --- | --- |
| Tıklamak | Dokunmak |
| Çift tıklamak | İki kez hızlıca dokunmak |
| Sağ tıklamak | Parmağı yarım saniye basılı tutmak |
| Sürüklemek | Önce dokunarak seçmek, sonra sürüklemek |
| Fare tekerleği | İki parmakla yakınlaştırmak |

Yalnızca mobil sürümde olanlar: **Geri Al / Yinele**, son çizimin otomatik saklanması ve
devre çalışırken ekranın kapanmaması. Yardım menüsünde bu farkları anlatan bir sayfa da vardır.
